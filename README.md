# 대한민국 법령 통합검색기

국가법령정보센터 공동활용 API에서 현행 법령, 행정규칙, 법령용어와 선택 지역의 자치법규를 함께 찾는 Windows용 로컬 Streamlit 앱입니다. AI 요약이나 법률적 판단은 제공하지 않습니다.

Claude Code로 이어서 작업할 때는 먼저 [인수인계 문서](docs/CLAUDE_HANDOFF.md)와 [작업 규칙](CLAUDE.md)을 읽으십시오. 이 문서에는 사용자 요구사항, 해결한 정확도 오류, 아직 구현하지 않은 UI·배포 작업이 구분되어 있습니다.

## 설치 및 설정

- Windows와 Python 3.11 이상이 필요합니다. `run.bat`은 Python 3.12 런처를 우선 사용합니다.
- 국가법령정보 공동활용 API 이용 승인을 먼저 받아야 합니다.
- 프로젝트 루트에 다음 내용의 `config.local.toml`을 만드십시오. 이 파일과 `data/cache.db`는 Git에서 제외됩니다.

```toml
api_key_file = "G:\\path\\to\\external-law-api-key.txt"
cache_path = "data/cache.db"
```

인증 파일은 단일 평문 키 또는 `7. 국가법령정보 공동활용: 값` 형식의 항목을 지원합니다. 값 자체를 설정 파일, 소스 코드, 로그, SQLite에 복사하지 마십시오.

## 실행과 검색 문법

`run.bat`을 실행하면 필요한 로컬 가상환경과 패키지를 준비하고 `127.0.0.1`에만 서버를 엽니다.

- `주차 방법`: 전국 자료만 검색하며 자치법규는 요청하지 않습니다.
- `@평택 주차 방법` 또는 `주차 방법 @평택`: 평택시와 상위 경기도 자치법규를 추가합니다.
- `@경기/평택 주차 방법`: 광역·기초 지역을 명시합니다.
- `@중구`처럼 이름이 중복되면 후보를 표시하며, 사용자가 하나를 선택하기 전에는 검색하지 않습니다.

지역 자료의 표시 순서는 기초자치단체, 광역자치단체, 법률, 대통령령, 총리령·부령, 행정규칙, 기타 상위 규정입니다. 지역 레지스트리는 2026-07-01 시행 체계의 16개 광역 코드와 229개 시·군·구 코드를 사용하며, 통합 지역의 과거 명칭은 현재 공식 코드로 연결합니다.

## 화면 구성

- 검색 결과는 최대 폭을 제한한 데스크톱 화면에서 법규 유형별 2열 카드로 표시됩니다. 좁은 화면에서는 1열로 재배치됩니다.
- 사이드바는 법률·시행령·시행규칙·행정규칙·자치법규별 건수와 문서 바로가기입니다. 사이드바 선택은 다른 결과를 숨기지 않으며 검색을 다시 실행하지 않습니다.
- 카드의 `미리보기`는 이미 가져온 본문 검증 결과와 캐시를 재사용합니다. 제목만 일치한 문서는 처음 열 때만 본문을 조회합니다. `검색 결과로 돌아가기`는 API를 호출하지 않습니다.
- 상단의 `비교하기`는 현재 검색 결과 중 두 문서를 좌우로 골라 정확 일치 조문을 나란히 봅니다. 법률↔조례뿐 아니라 모든 유형 조합이 가능하며, 위임 관계나 우선순위를 자동 판정하지 않습니다.
- AI 요약이나 유사어 확장 검색은 제공하지 않습니다.

## 캐시와 장애 동작

검색 목록과 본문 문맥은 SQLite에 별도로 저장되며 기본 유효기간은 24시간입니다. 같은 검색을 반복하면 유효한 캐시를 사용합니다. 화면의 새로고침은 캐시를 건너뛰고 공식 API를 다시 호출합니다. API 장애 때 만료 캐시가 있으면 조회 시각과 함께 이전 결과 경고를 표시하고, 없으면 해당 자료원만 오류로 표시합니다. 다른 자료원의 성공 결과는 유지됩니다. 앱을 재시작해도 `data/cache.db`의 캐시는 유지됩니다.

## 검증

단위 테스트:

```powershell
python -m pytest -v
```

실제 API 계약 테스트는 명시적으로 선택해야 합니다. 요청 URL과 인증값을 출력하지 않습니다.

```powershell
$env:RUN_LIVE_LAW_API = '1'
python -m pytest tests/integration/test_live_api.py -v
Remove-Item Env:RUN_LIVE_LAW_API
```

일부 자료원에 대한 이용 승인이 없으면 해당 테스트는 승인되지 않은 공식 엔드포인트라는 제한을 명시하고 xfail 처리합니다.

## 법적·출처 고지

검색 결과는 참고자료입니다. 최종 확인은 국가법령정보센터의 공식 원문과 소관기관 기준으로 하십시오. 검색기는 공식 링크만 제공하며 완전성, 최신성 또는 특정 사안에 대한 법적 결론을 보장하지 않습니다.

공식 자료(2026-08-12 확인):

- [국가법령정보 공동활용 OPEN API 목록](https://open.law.go.kr/LSO/openApi/guideList.do)
- [자치법규 목록 조회 API](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=ordinListGuide)
- [자치법규 본문 조회 API](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=ordinInfoGuide)
- [국가법령정보 공동활용 이용안내](https://open.law.go.kr/LSO/information/guide.do)
- [국가법령정보센터](https://www.law.go.kr/)

위 안내 페이지들에는 확인 가능한 게시일 또는 최종 수정일이 표시되지 않아 자료 연령을 판단할 수 없습니다. 따라서 2년 이상 된 문서일 가능성을 배제할 수 없습니다.
